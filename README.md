# Galactic

Shooter espacial. Tiene versión de escritorio (pygame) y de navegador (Phaser 3).

## Escritorio

```bash
pip install pygame
python3 galactic.py
```

Mueve la nave con ← → y dispara con Espacio.

## Navegador

```bash
cd web
python3 -m http.server 8000
```

Abre <http://localhost:8000>.

Flechas o WASD para mover, Espacio para disparar, X para la bomba y P para pausar. En el móvil, arrastra el dedo.
